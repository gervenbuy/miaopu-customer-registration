喆圓農產行｜一頁式客戶資料登記

包含檔案
index.html：支援手機的一頁式問卷。
Code.gs：寫入 Google Sheet 的 Google Apps Script。

設定方法
1. 在 Google Apps Script 建立新專案，貼上 Code.gs 全部內容。
2. 要使用既有試算表時，填入 SPREADSHEET_ID；要建立新表則保持空白。
3. 選擇 setup 函式執行，依 Google 提示授權。在「執行記錄」取得 Google Sheet 網址。
4. 選擇「部署」→「新增部署作業」→「網頁應用程式」。執行身分選「我」，存取權選「任何人」。若帳號管理政策未提供此選項，外部顧客便無法使用此部署。
5. 複製部署產生的 /exec 網址，貼到 index.html 末端的 SCRIPT_URL。
6. 將 index.html 放到您既有網站的主機。先填寫一筆測試資料，確認結果頁顯示「登記成功」，並到 Google Sheet 檢查新資料。
7. 將問卷網頁網址設定到 LINE 圖文選單的「客戶資料登記」按鈕。

欄位
填寫時間（自動）、大名、手機、LINE ID（選填）、店名、職務、店址。
手機與 LINE ID 以文字保存，保留手機開頭的 0。
表單透過一般 HTML POST 送出，在新頁顯示伺服器儲存結果，不將「開始送出」當成成功。
請勿分享 Google Sheet 的編輯網址給顧客，顧客僅需問卷網址。

目前交付的是可部署原始檔，尚未在您的 Google 帳號部署、也尚未測試實際寫入。
更新 GS 後，需編輯部署並選擇新版本；只儲存程式碼不會更新既有部署。
